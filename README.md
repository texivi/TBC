# TBC

texivi's birthday counter

## rust

My first ever rust project, just a simple reminder of my birthday incase you forgot :)

## install

```
git clone https://github.com/texivi/tbc
cd tbc
sh install.sh
```

needs rust and cron.

## usage

```
tbc            install the reminder
tbc uninstall  remove the reminder
```

it only runs on May 30th, any other day it does nothing.

## notes

- if ur  pc is off at 00:00 on May 30th, it won't work, keep it on, for me :)
